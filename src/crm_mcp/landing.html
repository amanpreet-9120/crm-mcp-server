What Claude can do here

Six tools, each shaped around a question a salesperson actually asks.

ToolWhat it does
get_deals_needing_attentionreadRanked open deals with plain-English reasons: stale, overdue, no next step.
get_pipeline_summaryreadTotals by stage, weighted forecast and win rate, computed in code.
get_accountreadOne company: contacts, deals and recent activity in a single call.
search_dealsreadFilter by owner, stage, value, inactivity or closing window.
log_activitywriteRecord a call, email or meeting and set the next step.
update_dealwriteChange stage, value or close date. Shows a preview until you confirm.

Write tools are switched off on this public demo, so Claude will tell you instead of changing data.

Built for production, not just a demo

The design choices that carry over to a real deployment.

  • Exact numbers. Forecasts and risk rules run in code, so Claude never does arithmetic over your data.
  • About 7× less context. Task-shaped tools return ranked answers instead of raw tables, which keeps responses fast and cheap.
  • Safe writes. Changes show a preview with forecast impact and only apply after the user agrees.
  • Self-correcting errors. A typo gets "Did you mean…?" so Claude recovers on its own.
  • Observable. Every tool call is logged with latency and size. Live numbers below.
  • Swappable data layer. One file talks to the database. Replace it with HubSpot, Salesforce, Pipedrive or Postgres.
